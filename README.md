# 🛍️ Proyecto eCommerce - React + Spring Boot

Este es un proyecto completo de eCommerce que incluye un **frontend moderno** desarrollado en **React con Tailwind CSS**, y un **backend robusto** basado en **Spring Boot** con autenticación y conexión a base de datos **PostgreSQL**.

---

## 🚀 Tecnologías utilizadas

### 🔧 Servidor - Spring Boot
- **Spring Web** – para la creación de APIs REST.
- **Spring Data JPA** – para persistencia de datos.
- **PostgreSQL Driver** – para conexión a base de datos.
- **OAuth2 Resource Server** – para autenticación segura.
- **Lombok** – para reducir código repetitivo.
- **Spring Configuration Processor**
- **Spring Boot DevTools** – para recarga automática en desarrollo.

### 💻 Cliente - React
- **React 18+** – para la creación de interfaces interactivas.
- **Tailwind CSS 3** – framework de estilos rápido y moderno.
- **@material-tailwind/react** – componentes UI personalizables.
- **npm i @react-oauth/google** - Autenticacion con google
